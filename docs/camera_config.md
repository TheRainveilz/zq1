## 4. 阈值与成像条件的绑定关系

按 `r`（兜孔半径）比例写的常量换成像条件仍成立：拐角角度、距离比、压痕半径比、
环带范围、聚类间隔。**下面这些不成立，相机一改就要重标**：

### 4.1 随工作距离 / 分辨率 / binning 变化

| 常量 | 当前值 | 说明 |
|---|---|---|
| `HOLE_R_MIN_RATIO` / `HOLE_R_MAX_RATIO` | 0.030 / 0.065 | 孔半径 ÷ 图宽。WD 或分辨率一变，这个比例就偏 |
| `HOLE_MIN_DIST_RATIO` | 0.060 | 相邻孔心最小间距 ÷ 图宽 |
| `OUTER_R_MIN/MAX_RATIO` | 0.18 / 0.60 | 兜底定位用的大圆半径范围 |

### 4.2 随曝光 / 增益 / 光源变化

| 常量 | 当前值 | 说明 |
|---|---|---|
| `REFINE_MIN_CONTRAST` | 12 | 孔内/台面灰度差下限。曝光降太多会让暗区的孔被整体丢弃 |
| `HOLE_HOUGH_P1` | 120 | Canny 高阈值，跟边缘梯度强度绑定 |
| `HOLE_HOUGH_P2` / `_FALLBACK` | 55 / 32 | 累加器阈值。孔找不全先动 fallback |
| `FLANGE_HOUGH_P2` | 20 | 同心 Hough 找翻边圆 |
| `MARK_HOUGH_P2` | 16 | 拐角压痕的形状级预筛，光源换极性后最容易失效 |
| `CLAHE_CLIP` / `CLAHE_GRID` | 2.0 / (8,8) | 台面纹理很平的图上 CLAHE 会放大噪点 |

### 4.3 随 JPEG 质量变化

| 常量 | 当前值 | 说明 |
|---|---|---|
| `MARK_CIRCULARITY_MIN` | 0.75 | 实测正面压痕圆度 0.78~0.89，**余量仅 0.03**。压缩率一降边缘发毛，圆度直接掉破线 |
| `MIN_VALID_MARKS` | 2 | 4 个拐角要求至少 2 个有效。圆度整体下滑时先降这个再降圆度阈值 |
| `RING_MIN_CONTOUR_PTS` | 24 | 压缩块效应会打断轮廓 |

### 4.4 随取景位置变化

| 常量 | 当前值 | 说明 |
|---|---|---|
| `HOLE_CHECK_COUNT` | 2 | 选孔按"ROI 完整在视场内 → 4 拐角完整数 → 孔壁对比度"排序。可见孔变少时余量下降 |
| `MIN_HOLE_COUNT` | 2 | 有效孔少于 2 直接 NG |

## 5. 换相机 / 改参数后的复检清单

按顺序做，每步不过就别往下走：

1. `python thrust_cage_flange_inspect.py --dir docs/ref --holes 0 --debug`
   跑基准图，对照第 3 节数字（孔半径、节圆残差、孔壁对比度、压痕圆度）
2. 看叠加图：蓝圈节圆是否套住所有孔心 → 青圈孔 ROI 是否套住翻边 → 绿框拐角是否压在压痕上
3. `python thrust_cage_flange_inspect.py --calib --dir docs/ref`
   核对 `CORNER_SPEC` 与 `MARK_R_RATIO_RANGE`，偏差超 5° / 0.1 就抄新值进头部
4. 正面样本至少 20 张，要求**全部判 OK**，且每张有 ≥2 个孔双特征全过（留余量）
5. 反面样本至少 20 张，要求**全部判 NG**，且 NG 代码是 `NG_NO_FEATURE`
   （出现 `NG_HOLE_NOT_FOUND` 说明孔都没找到，是定位问题不是特征问题，不算通过）
6. 边界样本（漏冲、油污、毛刺）逐张看叠加图，确认判定原因和肉眼一致
7. 全部通过后，更新本文件第 1、3 节数值和第 6 节变更记录，连同头部常量一起提交
